ホームプライバシーGoogle Drive利用について利用上の注意

プライバシーポリシー

お出入り職人および採寸ちゃんにおける情報の取扱い方針です。

1. 基本方針

お出入り職人シリーズは、利用者の業務データを必要以上に外部へ集めないことを重視しています。顧客、見積、請求、採寸などの業務データは、原則として利用者自身のPC・端末または利用者自身が選択した保存先で管理します。

2. Google Drive連携で扱う情報

採寸ちゃんとお出入り職人の間で案件情報を受け渡す場合、利用者が選択したGoogleアカウントのGoogle Driveを利用します。連携対象は、主として「採寸ちゃん連携」フォルダ内の連携用データです。

Google Driveの情報を広告配信、利用者プロファイリング、第三者への販売のために利用しません。

3. 外部サーバーへの保存

Google Drive連携で取得した業務データを、提供者が運営する独自クラウドサーバーへ集約・保存することを基本構成としていません。連携は、利用者の端末と利用者自身のGoogle Driveとの間で行う設計です。

4. 第三者提供

法令に基づく場合を除き、利用者のGoogleユーザーデータや業務データを第三者へ販売・提供しません。

5. データの管理と削除

利用者はGoogle Drive上の連携データを自身で確認・削除できます。また、Googleアカウントの設定から本アプリへのアクセス許可を取り消すことができます。

6. Google API Services User Data Policy

Google APIから取得した情報の利用および他アプリへの転送は、Google API Services User Data Policy（Limited Use requirementsを含む）に従います。

7. ポリシーの変更

機能や法令、Google APIの要件等の変更に応じて本ポリシーを改定することがあります。重要な変更がある場合は本ページで告知します。
